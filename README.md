# PWM-BASED-LED-CONTROL-AND-GIT-VERSION-CONTROL

## AIM:
To develop and analyse a PWM-based LED control program to switch an LED ON and OFF at one-second intervals, verify the PWM frequency and duty cycle, and manage the source code using Git through VS Code.

---

## Apparatus Required

| S. No. | Apparatus / Software | Specification |
|:---:|---|---|
| 1 | Development Board | PWM-supported microcontroller |
| 2 | LED | Standard LED |
| 3 | Resistor | Current limiting |
| 4 | Jumper Wires | Circuit connection |
| 5 | USB Cable | Programming and communication |
| 6 | Computer/Laptop | Windows |
| 7 | VS Code | Source code and Git management |
| 8 | Git | Version control |
| 9 | GitHub/GitLab | Remote repository |
| 10 | Microcontroller IDE/SDK | Required development environment |

---

## Procedure

1. Connect the LED to the PWM-supported GPIO pin of the development board.
2. Configure the PWM module, frequency, and duty cycle.
3. Develop the program to switch the LED ON and OFF at one-second intervals using PWM.
4. Build and compile the program.
5. Flash the program to the development board.
6. Observe the LED operation and verify the PWM frequency and duty cycle.
7. Open the project in VS Code.
8. Initialize a Git repository or clone the required remote repository.
9. Add the source code to the Git staging area.
10. Commit the verified source code with an appropriate commit message.
11. Push the committed changes to the remote Git repository.
12. Verify the updated source code in the remote repository.
